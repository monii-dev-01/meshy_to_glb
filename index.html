작업 로그

파일을 선택하세요. 파일 데이터는 이 브라우저 안에서만 처리합니다.
변환 방식 · Meshy .meshy v1 (MESHY.AI 헤더)의 AES-CTR 포장을 해제하고, GLB 내부의 EXT_meshopt_compression 데이터를 복원합니다. 원래 GLB의 WebP 텍스처, UV, 재질, 애니메이션 데이터는 가능한 한 유지합니다.
인터넷 · 첫 실행 시 공개 Meshoptimizer 디코더(JS/WASM)를 CDN에서 불러옵니다. 모델 파일 자체는 어디에도 전송하지 않습니다.
호환성 · 확인된 Meshy v1 파일만 지원합니다. Meshy에서 형식을 바꾸면 변환이 실패할 수 있습니다. 보호된 소스 모델은 사용 권한이 있는 경우에만 변환하세요.
